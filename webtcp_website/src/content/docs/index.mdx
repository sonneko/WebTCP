## WebTCP の特徴（M3 対応済み）

<CardGrid stagger>
	<Card title="Ed25519 署名と自己証明型 NodeId" icon="approve-check">
		すべてのパケットが送信元の Ed25519 署名で保護され（プロトコル v2）、NodeId は公開鍵の指紋。改ざん・なりすましは受信側で破棄されます。秘密鍵はブラウザでは IndexedDB に非抽出 CryptoKey として保存されます。
	</Card>
	<Card title="バイトストリーム指向の仮想 TCP" icon="rocket">
		バイト単位の Seq/Ack、ランダム ISN、60 KiB 超データの自動分割・再結合、部分読み取り（`read` / `readExact`）、Half-Close に対応します。
	</Card>
	<Card title="動的 RTO・輻輳制御・SACK" icon="setting">
		RFC 6298（Jacobson / Karn）による動的 RTO、RFC 5681 の Slow Start / Congestion Avoidance、3 重複 ACK による Fast Retransmit と SACK を実装しています。
	</Card>
	<Card title="単一 DataChannel 上のポート多重化" icon="random">
		1 本の WebRTC DataChannel 上で複数の仮想ポート・セッションを多重化し、距離ベクトル型ルーティングにより 3 ノード以上のマルチホップ転送も行えます。
	</Card>
	<Card title="NAT 越え・自動ブートストラップ" icon="globe">
		`bootstrap(searcher)` による指数バックオフ付き自動接続、動的 TURN 資格情報フック（`iceServersProvider`）、接続障害時の自動 ICE 再起動を備えます。
	</Card>
	<Card title="バンドラ不要・ゼロランタイム依存" icon="document">
		コアは `Uint8Array` / `DataView` と独自 `EventEmitter` で実装され、Node.js 組み込みに非依存。`tsc` の ESM 出力をブラウザから直接 import できます。
	</Card>
	<Card title="レベル付きロガー注入" icon="information">
		`debug` / `info` / `warn` / `error` / `silent` のログレベル制御に対応（既定は `warn` 以上）。カスタムロガーを `WebTCPNetwork` へ注入できます。
	</Card>
</CardGrid>
